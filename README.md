## 📖 Overview

**Findora** is an AI-powered Lost & Found platform designed to simplify the process of recovering lost belongings within educational institutions.

Instead of relying on manual searching, Findora intelligently matches lost and found reports using AI-driven similarity analysis based on item descriptions, categories, colors, brands, locations, and uploaded images.

The platform provides a secure, user-friendly experience with authentication, claim verification, notifications, and modern responsive UI.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/Soumya1709/Findora.git
```

```bash
cd Findora
```

---

## Backend Setup

```bash
cd backend
```

Install dependencies

```bash
npm install
```

Create

```text
.env
```

```env
PORT=5000

MONGO_URI=YOUR_MONGODB_URI

JWT_SECRET=YOUR_SECRET

CLOUDINARY_CLOUD_NAME=

CLOUDINARY_API_KEY=

CLOUDINARY_API_SECRET=

GOOGLE_CLIENT_ID=
```

Run backend

```bash
npm run dev
```

---

## Frontend Setup

```bash
cd frontend
```

Install

```bash
npm install
```

Create

```text
.env
```

```env
VITE_API_URL=http://localhost:5000

VITE_GOOGLE_CLIENT_ID=YOUR_GOOGLE_CLIENT_ID
```

Run

```bash
npm run dev
```
